# Agent Spec

## Overview
The **4x4 Road Trip Planner Agent** (`four_by_four_planner`) builds safe, day-by-day off-road and overlanding itineraries. Given a user's destination/region, trip duration, and 4x4 vehicle specifications (tire size, ground clearance/lift, transfer case 4WD/4Lo, locking differentials, fuel tank capacity, highway MPG, and recovery gear), the agent:
1. Finds candidate 4x4 trails from a curated trail catalog and live web search.
2. Deterministically validates whether the user's vehicle meets each trail's technical difficulty rating (1–10 scale) and minimum equipment requirements.
3. Calculates off-road fuel consumption (accounting for low-range/terrain MPG penalties) and enforces a mandatory 25% backcountry fuel reserve margin.
4. Checks live weather and elevation conditions for trailheads and recommends designated campsites and fuel stops for each day.
5. Persists user vehicle builds across turns and sessions using Vertex AI Memory Bank (`PreloadMemoryTool`, `add_session_to_memory`) and session state (`user:rig_profile`), while enforcing Human-in-the-Loop (HITL) confirmation for high-risk backcountry dispatches.

## Language
`python` (Google ADK).

## Architecture, Multi-Model Strategy & Sub-Agents
- **Pattern:** Coordinator Agent + Specialist `AgentTool` Sub-Agents with Runner-Wide Safety Plugins (`BasePlugin`) and Resumable Human-in-the-Loop (HITL) Execution.
- **Multi-Model Routing Matched to Task Complexity:**
  1. **Root Coordinator (`four_by_four_planner` — `gemini-3.8-flash`):** Orchestrates multi-step itinerary synthesis, deterministic tool calls, state/memory management, and HITL confirmation flows.
  2. **Fast Web Research & Compaction Specialist (`web_trail_researcher` & `LlmEventSummarizer` — `gemini-2.5-flash`):** Low-latency specialist sub-agent wrapped via `AgentTool` equipped exclusively with `google_search` for trail/closure lookups, and also used for sliding-window event compaction.
  3. **Deep Safety & Compliance Auditor (`safety_compliance_auditor` — `gemini-2.5-pro`):** High-reasoning specialist sub-agent wrapped via `AgentTool` for auditing complex multi-day remote traverses, extreme trails (`>= 6/10`), and compound mechanical/weather/fuel risk trade-offs.
- **Runner-Wide Plugins (`app/app_utils/safety_plugins.py`):**
  - `OffroadSafetyGuardrailPlugin(BasePlugin)`: Implements two-phase session-poisoning defense (`on_user_message_callback` + `before_run_callback`), automatic PII redaction across user prompts, tool args/results, and model outputs, strict Pydantic `BaseModel` tool output normalization, and structured Intent vs. Outcome tracking.
  - `ReflectAndRetryToolPlugin(max_retries=2)`: Automatic tool self-correction on transient failures.
  - `ContextFilterPlugin(num_invocations_to_keep=10)`: Keeps active LLM context bounded.
  - `BigQueryAgentAnalyticsPlugin`: Exports runtime analytics events when `BQ_ANALYTICS_DATASET_ID` is configured.

## Context & Memory Architecture (`app/app_utils/memory_config.py` & `app/app_utils/services.py`)
- **Cross-Session Memory Bank:** Configured with `VertexAiMemoryBankService` in production (`AGENT_ENGINE_ID`) and `InMemoryMemoryService` locally, backed by `memory_bank_config` (`ReasoningEngineContextSpecMemoryBankConfig`) defining both managed topics (`USER_PERSONAL_INFO`, `USER_PREFERENCES`, `KEY_CONVERSATION_DETAILS`, `EXPLICIT_INSTRUCTIONS`) and custom overlanding topics (`user_4x4_rig_build_profile`, `backcountry_safety_and_camping_preferences`).
- **Preload & Extraction Callbacks:**
  - `PreloadMemoryTool()` automatically retrieves relevant memories at the start of each turn.
  - `before_agent_callback=initialize_overlanding_state` initializes `user:`, `app:`, and `temp:` scoped state keys and populates `{user_rig_profile_summary}` and `{active_trip_region}` for dynamic system prompt injection.
  - `after_agent_callback=generate_memories_callback` triggers `await callback_context.add_session_to_memory()` to extract long-term memories at the end of each turn.
- **Context Compaction & Caching:**
  - `EventsCompactionConfig(compaction_interval=4, overlap_size=1, summarizer=LlmEventSummarizer(...))` summarizes older conversation turns automatically.
  - `ContextCacheConfig(min_tokens=1024, ttl_seconds=1800, cache_intervals=5)` caches static system instructions and tool declarations.

## Strict Pydantic Tool Schemas & Human-in-the-Loop (`app/tools.py` & `app/app_utils/typing.py`)
All tools enforce strict input types and return validated `StrictToolModel(BaseModel)` subclasses (`extra="forbid"`) with explicit `recovery_instructions` for self-correction:
1. **`search_curated_trails(region: str, max_difficulty: int) -> TrailSearchOutput`**
   - Searches the validated `list[TrailRecord]` catalog of 20 iconic 4x4 trails across Utah, California, Colorado, and Arizona.
2. **`check_rig_trail_compatibility(...) -> RigCompatibilityOutput`**
   - Deterministically computes `max_safe_difficulty` (1–10) and returns `verdict` (`APPROVED` or `REJECTED_UNSAFE_FOR_RIG`), `blocking_reasons`, `safety_warnings`, and `recovery_instructions`.
3. **`calculate_offroad_fuel_plan(...) -> FuelPlanOutput`**
   - Calculates degraded off-road MPG, total fuel burned, tank utilization percentage, 25% reserve compliance (`meets_25_percent_reserve_rule`), and required 5-gallon jerry cans.
4. **`get_trail_weather_and_elevation(location_name: str) -> TrailWeatherOutput`**
   - Queries OpenStreetMap Nominatim + Open-Meteo with deterministic fallback to `FALLBACK_WEATHER_BY_REGION` (`dict[str, RegionalWeatherBaseline]`).
5. **`save_user_rig_profile(...) -> SavedRigProfileOutput`**
   - Validates and persists `UserRigProfile` into `tool_context.state["user:rig_profile"]` and saves a `user_rig_profile.json` artifact via `tool_context.save_artifact`.
6. **`submit_backcountry_trip_registration(...) -> BackcountryPermitApprovalOutput` (Human-in-the-Loop)**
   - Wrapped with `FunctionTool(..., require_confirmation=requires_high_risk_confirmation)` and `tool_context.request_confirmation(...)` alongside `ResumabilityConfig(is_resumable=True)` on `App` to require explicit human confirmation for extreme trails (`>= 7/10`), solo advanced routes (`>= 6/10`), or NPS/BLM overnight permits.

## Observability, Structured Logging & PII Redaction (`app/app_utils/telemetry.py`)
- **OpenTelemetry Cloud Trace:** `otel_to_cloud = True` in `app/fast_api_app.py` with GenAI content capture disabled by default (`OTEL_INSTRUMENTATION_GENAI_CAPTURE_MESSAGE_CONTENT=NO_CONTENT`).
- **Structured JSON Logging:** `StructuredJsonFormatter` and `StructuredAuditLogger` emit single-line JSON records correlated with OpenTelemetry `trace_id` and `span_id` to stdout and Google Cloud Logging (`log_struct`).
- **Intent vs. Outcome Capture:** `IntentOutcomeTracker` records paired `IntentRecord` and `OutcomeRecord` (`IntentOutcomeAuditEntry`) across `user_prompt`, `agent`, `model`, and `tool` stages, exposed via `GET /audit/intent-outcomes`.
- **Deterministic PII Redaction:** `PiiRedactor` and `PiiRedactionFilter` scrub emails, phone numbers, SSNs, credit cards, API keys, 17-character VINs, and sensitive dictionary keys before logs, spans, or session events are emitted.

  - `deployment/terraform/cicd/`: Multi-project Staging + Production + CI/CD runner infrastructure with Workload Identity Federation (`wif.tf`) and GitHub repository bindings (`github.tf`).
- **GitHub Actions CI/CD (`.github/workflows/`):**
  - `pr_checks.yaml` (unit tests, integration tests, evaluation gate), `staging.yaml`, and `deploy-to-prod.yaml`.
- **Secret Management (`app/app_utils/secrets.py`):**
  - Retrieves secrets via Google Cloud Secret Manager (`get_secret`) using Application Default Credentials (ADC) with local environment fallback and `mask_secret` redaction.
