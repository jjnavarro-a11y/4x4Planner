# Agent Spec

## Overview
The **4x4 Road Trip Planner Agent** (`four_by_four_planner`) builds safe, day-by-day off-road and overlanding itineraries. Given a user's destination/region, trip duration, and 4x4 vehicle specifications (tire size, ground clearance/lift, transfer case 4WD/4Lo, locking differentials, fuel tank capacity, highway MPG, and recovery gear), the agent:
1. Finds candidate 4x4 trails from a curated trail catalog and live web search.
2. Deterministically validates whether the user's vehicle meets each trail's technical difficulty rating (1–10 scale) and minimum equipment requirements.
3. Calculates off-road fuel consumption (accounting for low-range/terrain MPG penalties) and enforces a mandatory 25% backcountry fuel reserve margin.
4. Checks live weather and elevation conditions for trailheads and recommends designated campsites and fuel stops for each day.

## Language
`python` (ADK — `--agent adk`, `--prototype` first).

## Architecture & Sub-Agents
- **Pattern:** Coordinator Agent + Specialist `AgentTool` (Option A).
- **Root Agent (`four_by_four_planner`):** Orchestrates trip planning, invokes deterministic Python function tools for trail lookup, rig compatibility, fuel-range math, and weather/elevation, and synthesizes the final day-by-day itinerary.
- **Sub-Agent (`web_trail_researcher`, wrapped via `AgentTool`):** Dedicated research specialist equipped exclusively with ADK's built-in `google_search` tool to look up trails not in the local catalog, current seasonal pass/gate closures, BLM/USFS dispersed camping rules, and nearby fuel stops. Isolating `google_search` in an `AgentTool` avoids Gemini API conflicts between built-in grounding tools and custom function declarations.

## Example Use Cases
1. **Compatible Multi-Day Moab Trip (Stock 4x4):**
   - *Input:* "Plan a 3-day 4x4 road trip in Moab, Utah for a stock Toyota 4Runner TRD Off-Road (31-inch tires, 9.6-inch clearance, 4Lo, rear locker, 23-gallon tank, 18 highway MPG, no winch, traveling solo)."
   - *Expected Output:* A 3-day itinerary featuring beginner/intermediate trails rated <= 4/10 (e.g., Shafer Trail / Potash Road, Gemini Bridges, Onion Creek), daily mileage + off-road fuel burn staying within 75% of tank capacity, fuel stops in Moab, dispersed/developed campsite recommendations, and current weather/flash-flood checks.
2. **Incompatible Trail Rejection & Safe Alternative (Capability Mismatch):**
   - *Input:* "Can I take my stock Subaru Outback (AWD, no 4Lo, 8.7-inch clearance, 29-inch tires) on the Rubicon Trail and Pritchett Canyon for a 2-day trip?"
   - *Expected Output:* Explicit safety block explaining why Rubicon Trail (8/10) and Pritchett Canyon (9/10) exceed the vehicle's maximum rating (2/10—lacks 4Lo, clearance, 35–37" tires, dual lockers, and winch), followed by safe scenic gravel/soft-road alternatives rated <= 2/10 in the same region.
3. **Remote Overlanding Fuel Reserve Warning:**
   - *Input:* "Plan a 2-day traverse of the White Rim Road (100 miles off-road) in a Jeep Wrangler with a 17.5-gallon tank getting 15 highway MPG."
   - *Expected Output:* Calculates degraded off-road MPG (~7.5–9.0 MPG in 4Lo/rough terrain), flags that 100 off-road miles + access roads exceeds the 75% usable fuel budget (violating the 25% reserve rule), and requires carrying auxiliary fuel (jerry cans/RotopaX) before starting the trail.

## Tools Required
1. **`search_curated_trails(region: str, max_difficulty: int)`**
   - *Purpose:* Searches the built-in curated catalog of iconic 4x4 trails (Moab, San Juan Mountains/Alpine Loop, Sierra Nevada, Death Valley, Arizona Backcountry, etc.) returning difficulty (1–10), length (miles), estimated hours, minimum tire size, minimum clearance, 4Lo/locker requirements, nearest fuel town, and camping notes.
   - *API/Auth:* Local deterministic Python catalog; no external auth required.
2. **`check_rig_trail_compatibility(trail_name: str, trail_difficulty: int, tire_size_inches: float, clearance_inches: float, has_4lo: bool, lockers: int, has_winch: bool, is_solo: bool)`**
   - *Purpose:* Deterministically computes the vehicle's maximum safe trail rating (1–10) and compares it against the target trail's difficulty and solo-travel risk. Returns a pass/fail verdict, max safe rating, and specific missing equipment warnings.
   - *API/Auth:* Local deterministic Python calculation; no external auth required.
3. **`calculate_offroad_fuel_plan(highway_miles: float, offroad_miles: float, trail_difficulty: int, highway_mpg: float, tank_capacity_gallons: float)`**
   - *Purpose:* Calculates estimated fuel consumption applying an off-road terrain penalty (e.g., 40%–60% MPG reduction based on trail difficulty), computes percentage of tank used, checks against the 75% max utilization threshold (25% mandatory reserve), and calculates auxiliary fuel gallons needed if exceeded.
   - *API/Auth:* Local deterministic Python calculation; no external auth required.
4. **`get_trail_weather_and_elevation(location_name: str)`**
   - *Purpose:* Geocodes the trail/region via OpenStreetMap Nominatim and fetches current multi-day forecast, precipitation probability, wind speed, temperature range, and elevation via Open-Meteo, flagging flash-flood or snow/ice hazards.
   - *API/Auth:* Public keyless HTTPS APIs (`nominatim.openstreetmap.org` and `api.open-meteo.com`) with graceful timeout/fallback handling; no API keys required.
5. **`web_trail_researcher` (`AgentTool` wrapping `google_search`)**
   - *Purpose:* Searches the web for trails outside the curated catalog, current USFS/BLM trail status, seasonal pass closures, permit requirements, and nearby gas stations/campgrounds.
   - *API/Auth:* Uses Vertex AI / Gemini built-in `google_search` grounding via application default credentials.

## Data Flow & State
1. **User Input:** User provides region/trails, duration (days), and vehicle specs (or the agent asks for missing critical rig specs before finalizing technical trail selections).
2. **Discovery & Lookup:** Root coordinator calls `search_curated_trails` first and supplements with `web_trail_researcher` (`google_search`) for uncovered regions, permits, or live closure info.
3. **Validation & Calculation:** For each candidate trail/day leg, the coordinator runs `check_rig_trail_compatibility`, `calculate_offroad_fuel_plan`, and `get_trail_weather_and_elevation`.
4. **Itinerary Synthesis:** The coordinator outputs a structured day-by-day plan containing: Trail Name & Difficulty (1–10), Rig Compatibility Status, Mileage & Fuel Budget (% tank used + reserve check + fuel stops), Weather/Hazard Advisory, and Campsite Recommendation.

## Constraints & Safety Rules
1. **Hard Rig Capability Block:** Never approve a trail in the primary itinerary whose technical difficulty rating (1–10) exceeds the vehicle's computed `max_safe_difficulty` from `check_rig_trail_compatibility` (e.g., vehicles without `has_4lo` are capped at rating 2/10; stock 4Lo vehicles on <=31" tires without lockers are capped at 4/10). If a user requests a harder trail, explicitly reject it as unsafe and propose compatible alternatives.
2. **25% Backcountry Fuel Reserve Rule:** Any leg between confirmed fuel stops that consumes >75% of `tank_capacity_gallons` (leaving <25% reserve) must be flagged with an explicit fuel starvation warning and the exact gallons of auxiliary fuel (jerry cans) required.
3. **Solo Travel & Recovery Advisory:** Any trail rated >=6/10 attempted solo (`is_solo=True`) or without a winch (`has_winch=False`) must include an explicit recovery/buddy-vehicle warning.
4. **Weather & Flash-Flood Hazard Warning:** If `get_trail_weather_and_elevation` reports >=40% precipitation probability or sub-freezing high-elevation conditions, the itinerary must warn against desert washes/slot canyons (flash-flood risk) or high alpine passes (snow/ice drift risk).
5. **Legal Trail Use (Responsible Trail Stewardship):** Only recommend legal, designated OHV/4x4 routes and authorized dispersed/developed camping areas; never advise off-trail cross-country driving.

## Edge Cases to Handle
- **Missing Vehicle Specs:** If the user asks for a 4x4 trip without specifying their vehicle, assume a stock 4WD with 4Lo (max rating 4/10) for initial suggestions while clearly stating the assumption and prompting the user for their exact rig specs.
- **AWD Crossover vs True 4x4:** Correctly distinguish AWD crossovers lacking a low-range transfer case (e.g., Subaru Outback, RAV4) from true 4WD vehicles with 4Lo, capping AWD vehicles at 2/10 graded dirt/easy gravel roads.
- **External Weather API Unreachable:** If Nominatim or Open-Meteo times out or is unreachable in a restricted network environment, return a structured fallback advisory instructing the driver to verify local NOAA/ranger station forecasts before departure rather than crashing.

## Success Criteria
1. **Rig Compatibility Accuracy:** 100% pass rate on eval cases testing that incompatible trails (where `trail_difficulty > max_safe_difficulty`) are blocked/warned and replaced with compatible alternatives.
2. **Deterministic Tool Trajectory:** In 100% of itinerary generation eval cases, the agent invokes `check_rig_trail_compatibility` and `calculate_offroad_fuel_plan` rather(than guessing MPG/ratings in free text).
3. **Fuel Reserve Enforcement:** 100% of eval cases where off-road leg consumption exceeds 75% of tank capacity trigger an explicit 25%-reserve warning with required auxiliary fuel volume.
4. **Overall Eval Quality Bar:** Achieve an average score >= 0.80 across `agents-cli eval run` rubrics covering itinerary completeness, safety guardrail adherence, and tool grounding.

## Assumptions
- **Model:** Uses the default latest Gemini model configured by `agents-cli scaffold create` on Vertex AI.
- **Trail Rating Scale:** Uses a standard 1–10 technical 4x4 difficulty scale (1–2: graded dirt/AWD; 3–4: stock 4WD with 4Lo; 5–6: modified 4x4 with 33"+ tires, lift, and rear locker; 7–8: extreme 4x4 with 35–37"+ tires, front & rear lockers, and winch; 9–10: buggy/dedicated rock crawler).
- **Weather/Geocoding APIs:** Uses free, keyless Open-Meteo (`api.open-meteo.com`) and OpenStreetMap Nominatim (`nominatim.openstreetmap.org`) APIs in Slice 1.
